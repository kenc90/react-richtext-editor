# Changelog

## 0.3.1

- Add the `themeColor` prop for customizing accent, focus, hover, and pressed colors.
- Add a theme color picker to the demo.

## 0.3.0

- Add `height` to size the visual and HTML source editors, with scrolling for fixed heights and vertical resizing in auto mode.
- Add `focused` to focus the visual editor when enabled, plus `onFocus` and `onBlur` handlers.
- Expand the demo with focus and height controls, and make its controls wrap on narrower screens.

## 0.2.0

- Add system, light, and dark theme support.

## 0.1.1

- Add HTML source editing with readable block formatting, preserved `<pre>` content, and draft/apply state management.
- Add the format painter, image insertion, configurable editor features, and rich HTML paste cleanup.
- Add Markdown shortcuts and a Normal text block format.
